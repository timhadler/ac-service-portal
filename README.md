# ac-service-portal
A simple, responsive AC service company website that allows customers to book appointments, contact the business, and learn about services offered.

## Live Demo
https://your-live-site-link.com

## Features

- Service overview pages
- Appointment re-direct to booking software
- Contact form
- Responsive design (mobile-first)
- Clean, modular JavaScript structure

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript

## Key Decisions

- Built as a multi-page site to better reflect a real business website and improve scalability
- Separated JavaScript by feature to avoid tightly coupled code
- Designed forms to be backend-ready for easy future integration
- Focused on simplicity and usability over frameworks
